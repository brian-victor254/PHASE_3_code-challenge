README
Overview
This project contains a collection of Python functions and classes designed to perform a variety of tasks, ranging from basic arithmetic operations to more complex object-oriented programming tasks. Each function or class demonstrates specific Python concepts or solves particular problems.

Functions and Classes
1. add_numbers(num1, num2)
Description:
This function takes two numbers as input and returns their sum.

2. is_even(number)
Description:
This function checks if a given number is even. It returns True if the number is even, and False otherwise.

3. reverse_string(text)
Description:
This function takes a string as input and returns the reversed version of that string.

4. count_vowels(text)
Description:
This function counts the number of vowels (a, e, i, o, u) in a given string, ignoring case sensitivity.

5. calculate_factorial(n)
Description:
This function calculates the factorial of a non-negative integer n. The factorial of n is the product of all positive integers less than or equal to n.

6. apply_decorator(func)
Description:
This function applies a decorator named decorator_func to another function. The decorator prints "Decorator Applied" before calling the original function.

7. sort_by_age(list_of_tuples)
Description:
This function sorts a list of tuples, where each tuple contains a name and an age, by age in ascending order.

8. merge_dicts(dict1, dict2)
Description:
This function merges two dictionaries. If there are any common keys, their values are summed up.

9. Car and ElectricCar Classes
Description:
The Car class represents a basic car with attributes for make, model, and year. The ElectricCar class inherits from Car and adds an additional attribute for battery_capacity. Both classes have a display_info method to print the car's information.

How to Run
Copy the code into a Python file (main.py or any other name).
Run the Python file using the command: python main.py.
Modify the sample usage code under the if __name__ == "__main__": section to test each function or class.
Requirements
Python 3.x
No additional libraries are required to run this code.
